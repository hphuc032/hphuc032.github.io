# carwyn.sec v1.0.0

The first public release of `carwyn.sec`, a bilingual cybersecurity portfolio
for Nguyen Hoang Phuc.

## Highlights

- English and Vietnamese portfolio routes
- Three evidence-conscious Operations case studies
- Professional experience and verified achievement records
- Reviewed MDX Security Log with one bilingual technical field note
- Safe, predefined portfolio Terminal commands
- Network Sphere and directional water-wake interaction with static,
  touch-friendly, and reduced-motion behavior
- Responsive editorial layouts and accessibility-focused keyboard, focus,
  reflow, touch-target, and reduced-motion behavior
- Public-safe CV and automated static deployment to GitHub Pages

## Platform

The site is built with Next.js App Router, React, TypeScript, Tailwind CSS,
GSAP, React Three Fiber, Three.js, and MDX. GitHub Actions produces and deploys
the static Pages artifact while the repository retains a server-capable Next.js
build mode.

## Known limitations

- Native Firefox and Safari coverage is not comprehensive.
- No public field RUM or CrUX dataset is available; performance figures are
  synthetic measurements.
- The public PDF has not received a formal PDF accessibility audit.
- Some case studies remain intentionally concise until more publishable evidence
  is reviewed.

The `v1.0.0` tag and GitHub Release are intentionally pending final human
approval.
